# 👜 Bagora – Luxury Handbag E-Commerce Platform

**Bagora** is a modern luxury e-commerce platform designed for handbag lovers. It provides an elegant and user-friendly shopping experience where customers can explore premium handbags and leather accessories through a stylish online store.

## 🌟 Project Overview

Bagora aims to combine luxury fashion with a smooth digital shopping experience. The platform features an elegant interface, premium product presentation, and a dedicated shopping cart experience.

## ✨ Features

- **Luxury UI Design:** Modern and elegant interface.
- **Product Showcase:** Explore premium handbags and leather goods.
- **Home Page:** Attractive landing page introducing the brand.
- **Handbag Collection:** Browse available handbag products.
- **Shopping Cart:** Dedicated cart interface for selected products.
- **Responsive Design:** Designed for a smooth browsing experience across devices.
- **Backend API:** Express-based backend architecture.

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React Icons

### Backend
- Node.js
- Express.js
- CORS
- Dotenv
- Morgan

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/2410305014/bagora.git
```

### 2. Navigate to the Project

```bash
cd bagora
```

### 3. Install Dependencies

```bash
npm run install:all
```

### 4. Start the Backend

```bash
npm run server
```

### 5. Start the Frontend

Open another terminal and run:

```bash
npm run client
```

The frontend will start using Vite. Open the local URL displayed in your terminal.
